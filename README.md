# 📱 ระบบจัดการคิวงาน Real-Time สำหรับ Android (v2)

โปรแกรมจัดการคิวงานพร้อมระบบ Real-Time ซิงค์ข้อมูลข้ามเครื่องทันที ออกแบบให้ใช้งานง่ายบนมือถือ Android

## ไฟล์ภายใน ZIP
1. `standalone_offline.html`: ไฟล์เดี่ยว ดับเบิ้ลคลิกเปิดบนเว็บเบราว์เซอร์หรือบนมือถือได้ทันที ไม่ต้องติดตั้งโปรแกรมใดๆ (บันทึกข้อมูลในเครื่อง)
2. `server.js` + โฟลเดอร์ `public`: ระบบ Real-Time เต็มรูปแบบผ่าน Socket.io เมื่อมีคนแก้ไขหรือกดสลับปุ่มเขียว/แดง ทุกเครื่องที่เปิดลิงก์อยู่จะเปลี่ยนตามทันที

## วิธีเปิดใช้งานโหมด Real-Time (แชร์ลิงก์ให้คนอื่น)
1. ติดตั้ง Node.js
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์:
   ```bash
   npm install
   npm start
   ```
3. เปิดเบราว์เซอร์: `http://localhost:3000` หรือนำขึ้นโฮสติ้งฟรีเช่น Render.com หรือ Glitch.com เพื่อรับลิงก์ส่งให้เพื่อน
